# Proč jsou zelená jablka GOATed
Zelená jablka (odrůdy jako Granny Smith) jsou naprosto nejlepší ovoce na světě. Tady jsou důvody, proč tomu tak je.
![Čerstvá zelená jablka](images/jablko1.jpg)
[Více o odrůdě Granny Smith](https://cs.wikipedia.org/wiki/Granny_Smith)
Hlavní výhody:
- Skvělá kyselkavá chuť
- Méně cukru než červená jablka
- Perfektně křupou
